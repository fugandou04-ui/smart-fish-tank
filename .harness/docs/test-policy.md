## 固件测试

### 编译验证（自动化）

```bash
# Arduino CLI
arduino-cli compile --fqbn esp32:esp32:esp32c3 src/firmware/main.ino

# PlatformIO
pio run -e esp32-c3-mini
```

每次提交前必须通过编译。

### 单元测试（手动/串口）

- **温度传感器**：读取 DS18B20，与水温温度计对比 ±0.5℃
- **OLED 显示**：检查 4 页面切换、温度/时钟/控制显示正常
- **水泵控制**：继电器吸合 5V，水泵启动，10 秒后关闭
- **舵机控制**：SG90 0°-180° 转动正常
- **WS2812B**：12 颗灯珠全亮，渐变/流水模式正常
- **WiFi**：AP 模式可连接，STA 模式可获取 IP，Web 控制台可访问

### 集成测试

完整原型装配后：

- 启动 → 显示温度
- Web 控制台控制水泵开/关 → 听到继电器吸合 + 水泵启动
- Web 控制台控制舵机 → 喂食器旋转
- 长时间运行（24h） → 无崩溃、无重启、温度读数稳定

## 文档一致性核查

由 `verifier` rein 执行：

- **频次**：每周一次全文档巡查
- **触发**：任何文档修改后必查
- **核查范围**：README / MEMORY / config.h / 电路文档 / PCB 文档 / 结构文档 / BOM
- **核查项**：GPIO / 成本 / 尺寸 / 器件型号 / 接口定义

## 装配验证

参考 `docs/process/装配说明书/`，按顺序：

1. 焊接 PCB（先低后高：贴片 → 直插）
2. 装入底座 → 水泵
3. 安装 PCB 支撑柱
4. 装入缸体
5. 装入背滤盒
6. 安装缸盖
7. 通电测试

## 验收标准（DoD for prototype）

- [ ] 编译通过（无 warning）
- [ ] 6 大功能测试通过
- [ ] 24h 老化测试无重启
- [ ] 所有文档与实物一致（verifier 签字）
- [ ] BOM 实际采购成本 ≤ 100 元
- [ ] GitHub 仓库同步
