### Worktree 物理布局
- 主 checkout：`E:\Mavis项目\智能鱼缸` —— 永远在 `main`，保持干净
- Feature worktrees：`E:\Mavis项目\智能鱼缸\.worktrees\feature-<scope>-<name>\`
- `.worktrees/` 已在 `.gitignore` 中排除（commit `872e59e` 已加入）

### 未来规则
1. **任何代码/文档改动必须走 worktree + feature 分支**
2. **feature 完成 → merge → dev → 审核 → merge → main → 删除 feature 分支 + worktree**
3. **hotfix 例外：可绕过 dev，直接 main + dev 双合并**（见 `.harness/workflows/hotfix.md`）
4. **冲刺收尾 checklist 必须包含"worktree 清理"项**
