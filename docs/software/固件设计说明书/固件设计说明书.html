1.2 模块划分

模块名称职责对外接口
------------------------
**WiFiManager**WiFi连接管理，自动重连，AP/Station模式切换init() / connect() / getStatus()
**WebServer**HTTP服务器，处理API请求，提供Web界面handleRoot() / handleAPI() / handleSet()
**DeviceControl**各设备的统一抽象与控制接口setPump() / setLED() / setServo() / getTemp()
**SensorManager**温度采集与传感器数据管理readTemp() / getAverage()
**Scheduler**定时任务调度（喂食、开关灯）addTask() / checkTasks() / runTask()
**ConfigManager**配置存储与读取（Flash分区）save() / load() / reset()
**OLEDDisplay**OLED屏幕驱动与界面显示displayStatus() / displayTemp()

4.2 状态显示区

功能描述数据源
--------------------
当前温度显示水温（带单位℃）DS18B20
水泵状态ON/OFF 指示灯GPIO3状态
LED状态颜色预览 + 亮度百分比GPIO5/PWM
喂食状态下次喂食时间Scheduler
连接状态WiFi IP / 连接失败WiFiManager
运行时间设备运行时长system uptime

4.3 控制面板

4.3.1 水泵控制

  • 开关按钮：一键开启/关闭
  • 状态指示：绿色=运行中，灰色=关闭
  • 自动模式：设置运行间隔（如每2小时运行15分钟）

    • 4.3.2 LED灯控制

  • 颜色选择器：RGB色盘或预设颜色（白/蓝/红/绿/紫/暖黄）
  • 亮度滑块：0-100% 调节PWM占空比
  • 快速模式：日出模式（渐亮）/ 日落模式（渐暗）/ 彩虹模式
  • 定时开关：与定时任务联动

    • 4.3.3 喂食控制

  • 立即喂食：手动触发舵机旋转
  • 食量设置：小/中/大 三档（对应舵机旋转角度）
  • 喂食日志：记录最近10次喂食时间

    • 4.4 定时设置

    任务类型可配置项
    ------------------
    **喂食定时**时间点（小时:分钟）、重复（每天/工作日/周末）、食量
    **灯光定时**开灯时间、关灯时间、亮度、颜色
    **水泵定时**运行时间段、间歇比例

    4.5 设备配置

  • WiFi设置：选择网络/输入密码/测试连接
  • 显示设置：OLED屏幕亮度（0-255）、显示内容切换
  • 恢复出厂：清除所有配置
  • 固件信息：显示版本、运行时间、内存使用

    • 4.6 API接口设计

    接口方法参数返回

    `/api/pump`POST`{"action":"on/off"}``{"success":true}`

    五、配置存储方案

    5.1 存储介质选择

    方案优点缺点推荐度
    --------------------------
    **Preferences（Flash）**API简单，断电保存，寿命长写入次数有限（约10万次）★★★★★
    **EEPROM模拟**传统方案ESP32无真实EEPROM，模拟慢★★★
    **SPIFFS**可存储文件写入慢，不适合频繁更新★★★★
    **SD卡**大容量增加硬件成本★★

    推荐方案：使用 ESP32 内置 Preferences 库

    5.3 读写策略

  • 启动时：从Flash加载完整配置到内存结构体
  • 运行时：优先读写内存，异步写入Flash
  • 写入时机：
  • 用户操作触发设置时写入
  • 定时任务修改配置时写入
  • 避免频繁写入（如温度每秒上报不写入Flash）
  • 数据校验：
  • 存储CRC校验码
  • 启动时校验完整性，损坏则使用默认值

    • 5.4 安全考虑

  • WiFi密码使用Base64简单编码存储（非明文）
  • 提供恢复出厂设置功能（清除所有配置）
  • 固件版本升级时保留用户配置（版本兼容）

    • 六、扩展功能预留

    功能说明实现难度
    ---------------------
    **OTA升级**Web界面上传固件升级中等
    **MQTT对接**接入Home Assistant等平台中等
    **水质监测**增加pH值、浑浊度传感器需硬件
    **摄像头**远程查看鱼缸画面需硬件
    **声控**接入Alexa/小爱同学简单

    七、注意事项与风险点

  • GPIO复用：GPIO0/1用于I2C，需确保OLED地址不冲突（通常0x3C）
  • PWM限制：ESP32-C3有4个PWM通道，注意舵机和LED引脚分配
  • 温度采样间隔：DS18B20建议采样间隔≥1秒
  • WiFi重连：实现看门狗，防止WiFi断开后死机
  • Flash写入：避免在中断中写入Flash
