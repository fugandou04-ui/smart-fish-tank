一、装配前准备

1.1 所需工具

工具用途
------------
十字螺丝刀固定螺丝
尖嘴钳夹持小零件
热风枪/电烙铁焊接线束
万用表检查通断
酒精棉片清洁表面
硅胶密封防水

1.2 检查物料

按照BOM清单核对所有物料，确保无缺失。

二、底座组装

2.1 安装PCB主板

  • 将PCB主板放置在底座腔内
  • 对准4个定位柱
  • 用螺丝固定4个角

    • 注意：轻拿轻放，避免划伤PCB

    2.2 安装水泵

  • 将水泵放入水泵固定座
  • 调整水泵方向（进水口朝下）
  • 用硅胶密封水泵安装孔
  • 连接水管（进水管+出水管）

    • 2.3 安装舵机

  • 将舵机放入喂食器壳
  • 对准轴孔
  • 用螺丝固定
  • 连接舵机线到PCB（J4接口）

    • 2.4 安装OLED屏幕

  • 将OLED屏幕嵌入前面板凹槽
  • 排线从背面走线
  • 连接I2C排线到PCB（J2接口）

    • 2.5 安装温度传感器

  • 将DS18B20探头穿过防水塞
  • 从缸体内部穿入底座
  • 连接传感器线到PCB（J3接口）

    • 2.6 合上底座上盖

  • 检查所有线束是否整理好
  • 对准卡扣
  • 均匀按压四周
  • 用螺丝固定上盖

    • 三、缸体组装

    3.1 清洁亚克力板

    用酒精棉片擦拭所有亚克力板，去除保护膜和灰尘。

    3.2 粘接缸体

  • 底板粘接
  • 在底板边缘涂抹氯仿
  • 对准侧板粘接面
  • 压紧固定
  • 等待30秒初固定
  • 侧板粘接
  • 依次粘接4块侧板
  • 每块粘接后等待30秒
  • 确保45°倒角对齐
  • 粘接完成后静置24小时

    • 注意：氯仿有毒，佩戴口罩和手套，在通风环境下操作

    3.3 安装过滤盒

  • 将生化棉放入过滤盒
  • 将过滤盒放入底座卡槽
  • 确认可拆卸方向

    • 四、总装

    4.1 缸体与底座配合

  • 检查密封圈是否安装到位
  • 将缸体对准底座卡槽
  • 均匀下压直至完全配合
  • 检查四周缝隙是否均匀

    • 4.2 连接水管

  • 进水管：水泵 → 缸内
  • 出水管：过滤盒 → 缸内
  • 用快插接头固定

    • 4.3 安装LED灯条

  • 撕开LED背胶
  • 沿缸体顶部粘贴
  • 连接线束到PCB（J1接口）

    • 4.4 安装缸盖

  • 对准喂食口位置
  • 合上缸盖
  • 检查开合顺畅

    • 五、电气检查

    5.1 通电前检查

    检查项方法判定
    --------------------
    电源接口目视检查无虚焊
    传感器接口轻拉测试无松动
    继电器接口目视检查无短路
    OLED排线检查连接无脱落

    5.2 首次通电

  • 连接USB电源
  • 观察OLED屏幕是否亮起
  • 等待WiFi连接提示
  • 用手机搜索WiFi热点

    • 六、注意事项

    6.1 防水要求

  • 所有线缆穿孔处使用硅胶密封
  • 底座上盖与缸体接触面使用密封圈
  • 水泵安装后做24小时浸水测试

    • 6.2 静电防护

  • 焊接时佩戴防静电手环
  • PCB避免裸手触碰焊点
  • 存放时使用防静电袋

    • 6.3 安全提示

  • 氯仿有毒，通风操作
  • 加热棒使用时注意防烫
  • USB电源不超过5V

    • 七、常见问题

    问题原因解决方法
    ----------------------
    OLED不亮排线松动重新插接排线
    水泵不转继电器故障检查继电器接线
    温度显示异常传感器未连接检查J3接口
    WiFi连接失败WiFi非2.4G使用2.4G频段
