## §1 装配流程（12 步）

> **总原则**：从上到下、从外到内、先电气后机械、可拆卸件最后装。每步配检查表，全部勾选方能进入下一步。

### Step 1 — 底座装配（外壳 + 上盖骨架）

**目标**：完成底座外壳 PT-01 与上盖 PT-02 的物理装配（不含电子件）。

| # | 操作 | 工具 | 判定标准 |
|---|------|------|----------|
| 1.1 | 检查 PT-01 底座外壳内腔无杂物、无打印残料 | 目视 | 内腔清洁，4 角水泵凸台在位 |
| 1.2 | 检查 PT-02 上盖 4×M3 螺钉孔、4×φ6 定位柱完整 | 目视 + φ3 销试插 | 螺钉孔不滑丝，定位柱无偏斜 |
| 1.3 | 在底座外壳内腔中央水泵凸台涂抹薄层 704 硅胶 | 注射器 | 硅胶环形连续，无堆积 |
| 1.4 | 将 PT-07 水泵固定座（TPU 减震套朝下）压入凸台 | 手动压入 | 听到「咔」声，座体无翘起 |
| 1.5 | 将水泵放入 PT-07，4 颗 M2.5×8 螺钉对角拧紧 | 螺丝刀（扭矩 0.2 N·m） | 螺钉齐平、不滑丝 |
| 1.6 | 把 2 个 PT-11 快接头拧入水泵座进出水口（生料带 2 圈） | 手动 | 拧紧不松动，锥形锁紧段朝外 |
| 1.7 | 暂时不上盖，留待 Step 3 走线后再合 | — | — |

**检查表**：
- [ ] 底座外壳无可见损伤
- [ ] 水泵座安装牢固（手动推摇无松动）
- [ ] 快接头方向正确（进出水管接好后无折弯）

> ⚠️ **关键**：底座内**不再放置 PCB**（v2.0 已将 PCB 移至上盖上方）。底座内**仅放水泵**。

---

### Step 2 — 主板（PCB）预装

**目标**：将 PCB 固定到 PT-02 上盖上方，焊接电源 + 主控基本电路。

| # | 操作 | 工具 | 判定标准 |
|---|------|------|----------|
| 2.1 | 用 4 颗 M3×8 螺钉将 PCB 固定到 PT-02 上盖 4 个定位柱 | 螺丝刀（扭矩 0.3 N·m） | PCB 水平，4 角齐平 |
| 2.2 | 检查 E-02 AMS1117-3.3V 焊接：输入 10μF + 100nF，输出 10μF + 100nF | 目视 + 万用表通断 | 无虚焊、无短路，**E-12 10μF 仅用于 LDO**（不可与 E-11 1000μF 混用） |
| 2.3 | 检查 ESP32-C3 Mini 排针焊接：VDD / GND / GPIO0/1/3/4/5/6/7 | 万用表通断 | 全部连通，无桥接 |
| 2.4 | 焊接 E-08 PPTC 1A + E-09 TVS SMBJ5.0A | 电烙铁 | 极性正确（TVS 阴极朝 VBUS） |
| 2.5 | 焊接 E-16 USB Type-C 接口（16Pin 贴片） | 电烙铁 / 热风枪 | 16 个焊点饱满、无桥接 |
| 2.6 | **临时通电验证**：插入 5V/2A，测 TP3 = 3.3V ± 0.1V | 万用表 | 电压正常，芯片无异常发热 |

**检查表**：
- [ ] PCB 4 角螺钉已紧固
- [ ] LDO 输入/输出电容**确为 10μF**（**禁止**误用 1000μF）
- [ ] 3.3V 正常，电流 ≤ 100 mA（空载）
- [ ] Type-C 接口插入线材无松动

> ⚠️ **GPIO 锁定**（电路 V1.1 + 固件 v1.1 已统一）：
> - GPIO0 = OLED SDA
> - GPIO1 = OLED SCL
> - **GPIO7 = DS18B20**（**非 GPIO2**，避让 strapping 引脚）
> - GPIO3 = 水泵继电器（低电平触发）
> - GPIO4 = 舵机 PWM
> - GPIO5 = WS2812B 数据
> - GPIO6 = 加热棒光耦（预留）

| # | 操作 | 工具 | 判定标准 |

| 3.1 | OLED 模块排线（J2 / XH2.54 4Pin）焊接完成 | 电烙铁 | 4 芯排线 VCC/GND/SDA/SCL 顺序正确 |

**检查表**：
- [ ] OLED 排线无虚焊
- [ ] 屏幕无物理划伤
- [ ] 屏幕与上盖齐平（不凸不凹）

### Step 4 — 接线（电源 + 外设线束）

**目标**：连接所有外设线束到 PCB。**注意每根线的去处**。

| # | 线束 | 来源 → 去向 | 接线端 | 备注 |
|---|------|-------------|--------|------|
| 4.1 | USB 电源线 | Type-C → PT-01 底座开口 | PCB USB 焊盘 | 5V/2A 供电 |
| 4.2 | 水泵线 | 底座水泵 → PT-02 出口 | 2Pin 5.08 mm 端子 J1 | 5V + GND |
| 4.3 | 舵机线 | 喂食器 SG90 → PT-02 | 3Pin 2.54 mm 端子 J3 | 5V/PWM/GND |
| 4.4 | LED 排线 | 缸盖 WS2812B → PT-02 | 4Pin 端子 J2 | 5V/DATA/GND/GND |
| 4.5 | 温度探头线 | 缸内 DS18B20 → 前面板 φ8 孔 → PT-02 | 3Pin 2.54 mm 端子（DQ/VDD/GND） | **DQ 接 GPIO7** |
| 4.6 | 串口调试线 | ESP32 TX/RX/3V3/GND → 1×4 排针 | 排针 | 烧录用 |

| # | 操作 | 判定标准 |
|---|------|----------|
| 4.7 | 所有端子用扎带 + 魔术贴整理到 PT-02 上方 | 线束无悬空、无压迫 |
| 4.8 | **万用表通断检查**：每根线两端电阻 < 1Ω | 无断路、无错接 |
| 4.9 | **短路检查**：5V 与 GND 之间电阻 > 100 kΩ（断电状态） | 无短路 |

**检查表**：
- [ ] **DS18B20 数据线**确认接到 **GPIO7**（电路原理图 3.4 节 + 固件 v1.1 已锁定）
- [ ] **DS18B20 4.7KΩ 上拉**已焊接在 GPIO7 与 3.3V 之间
- [ ] **WS2812B 数据线**串联 220Ω 电阻（位于主控端）
- [ ] **继电器续流二极管 1N4007**反向并联在继电器线圈（阳极 GND / 阴极 VCC）
- [ ] 无冷焊 / 桥接 / 漏焊

### Step 6 — 缸体粘接（侧板 + 底板）

**目标**：把 5 块亚克力板粘接成 150×150×150 mm 水密缸体。

> **粘接完成后必须静置 24 h 才能注水**。本步可在 Step 1-5 完成的当天开始，24 h 后与 Step 7-12 并行。

| # | 操作 | 工具 | 判定标准 |
|---|------|------|----------|
| 6.1 | 戴丁腈手套 + 口罩 + 护目镜，通风橱内操作 | 防护用品 | — |
| 6.2 | 用无水乙醇擦拭 5 块板的 45° 斜角面 | 无纺布 + 乙醇 | 表面无油污 / 灰尘 |
| 6.3 | **确认开孔方向**（粘反不可逆）：<br>A（φ8）→ 前面 / B（φ6）→ 右侧 / C（完整）→ 左侧 / D（支架槽）→ 后面 | 标识 | 4 块板方向在台面上摆好并标记 |
| 6.4 | 将底板 PT-03 平放，4 块侧板的 45° 斜角沿底板边缘对齐 | 夹具 / 直角治具 | 缝隙 < 0.1 mm，4 角 90° |
| 6.5 | 注射器抽取氯仿，沿底板-侧板接缝均匀注入（毛细作用自动渗入） | 注射器 + 22 G 针头 | 胶量适中，无流挂 |
| 6.6 | 依次粘接 4 块侧板，每粘一块用夹具固定 5 min | 夹具 | 板间缝无错位 |
| 6.7 | 4 块侧板相互接缝用同样方法粘接 | 注射器 | 90° 角用角尺校验 ±0.5° |

## §5 不合格处理

> **目的**：把故障归类、定级、可追溯。每一台不合格品都有「故障单 + 处理记录 + 最终去向」。

### 5.1 故障分类（按严重度 + 部位）

#### 5.1.1 按严重度

| 等级 | 名称 | 定义 | 示例 |
|------|------|------|------|
| **S1** | **致命** | 影响安全、无法修复 | USB 过压无保护、亚克力缸体粘接开裂、AC 强电击穿 |
| **S2** | **严重** | 主要功能失效，可返工 | 水泵不转、OLED 不亮、温度读数偏差 > 2°C、WiFi 无法连接 |
| **S3** | **一般** | 次要功能异常，可现场修复 | LED 单颗不亮、按键手感差、OLED 单个坏点、外壳划痕 |
| **S4** | **轻微** | 外观/包装问题，不影响功能 | 序列号标签歪斜、说明书折角、配件缺件 |

#### 5.1.2 按部位

| 部位 | 常见故障 | 责任方 |
|------|----------|--------|
| 结构件 | 亚克力开裂、3D 打印分层、卡扣断裂 | 机械工程师 |
| 电气件 | 虚焊、短路、器件损坏 | 电气工程师 |
| 固件 | 启动失败、WiFi 异常、传感器读数错误 | 嵌入式工程师 |
| 装配工艺 | 漏装、错装、扭矩不足 | 装配工 + QC |
| 测试 | 测试不充分、误判 | 测试工 + QC |

### 5.2 返工流程

```
┌──────────────────────────────────────────────────────┐
│ Step 1：发现不合格品                                  │
│   - 测试员/QC 在任一阶段发现 FAIL，立即标记           │
│   - 贴红色「不合格」标签 + 填写《不合格品处理单》     │
└────────────────────┬─────────────────────────────────┘
                     ↓
┌──────────────────────────────────────────────────────┐
│ Step 2：故障定位                                      │
│   - 测试工 + 相关工程师（机械/电气/嵌入式）共同定位    │
│   - 必要时用示波器、万用表、X-ray 等工具诊断          │
│   - 填写《故障分析报告》（FA Report）                 │
└────────────────────┬─────────────────────────────────┘
                     ↓
┌──────────────────────────────────────────────────────┐
│ Step 3：返工方案评审                                  │
│   - S1/S2：必须评审（PM + 工程师 + QC）              │
│   - S3：现场工程师即可决定                            │
│   - S4：QC 决定                                      │
│   - 输出《返工方案》（含：新器件 BOM + 工时 + 责任人） │
└────────────────────┬─────────────────────────────────┘
                     ↓
┌──────────────────────────────────────────────────────┐
│ Step 4：执行返工                                      │
│   - 责任工程师按方案拆解、修复、更换                    │
│   - 报废件贴「已报废」标签并隔离                       │
│   - 返工过程拍照存档                                  │
└────────────────────┬─────────────────────────────────┘
                     ↓
┌──────────────────────────────────────────────────────┐
│ Step 5：重新测试                                      │
│   - 返工完成后**从头跑** §1-§3 全部测试               │
│   - 不可只测返工点（避免遗漏次生故障）                │
│   - 填写《返工后测试记录》                            │
└────────────────────┬─────────────────────────────────┘
                     ↓
┌──────────────────────────────────────────────────────┐
│ Step 6：最终判定                                      │
│   - ✅ 全部 PASS → 重新贴「合格」标签 → 入库          │
│   - ❌ 仍 FAIL → 进入「报废评估」（§5.3）             │
└──────────────────────────────────────────────────────┘
```

### 5.3 报废标准

> 当返工成本 > 重新生产成本时，整机或部件应直接报废。

#### 5.3.1 整机报废

| 条件 | 说明 |
|------|------|
| S1 致命故障 | 如：AC 隔离击穿、缸体结构性开裂（不可靠修补） |
| 累计返工 ≥ 3 次 | 反复出问题的「问题机」，生产效率低、风险高 |
| 关键物料错配 | 如 ESP32 模组非正版、电源芯片假货 |
| 用户已开封且损坏 | 售后维修成本 > 替换成本 |

#### 5.3.2 部件报废

| 部件 | 报废条件 |
|------|----------|
| 亚克力缸体 | 粘接缝白雾 / 长度 > 5 mm、缸体结构性开裂 |
| 3D 打印件 | 关键尺寸偏差 > 0.5 mm、可见分层、卡扣断裂 |
| PCB | 虚焊无法修复 / 走线烧毁 / 模组损坏 |
| ESP32 模组 | 无法烧录固件 / 启动失败 / GPIO 损坏 |
| OLED | 坏点 > 3 个 / 全屏花屏 / I2C 无响应 |
| 水泵 | 堵转电流 > 400 mA / 出水流量 < 50 mL/min |
| 继电器 | 触点粘连 / 线圈短路 / 吸合异响 |
| LED 灯条 | 焊接处短路、灯珠损坏 > 1 颗 |

#### 5.3.3 报废处理流程

| Step | 操作 | 责任方 |
|------|------|--------|
| 1 | 贴「已报废」红标签，注明报废原因 + 日期 + 经手人 | QC |
| 2 | 隔离到「报废品区」物理隔离，不与新品混放 | 仓管 |
| 3 | 填写《报废单》并签字 | QC + PM |
| 4 | 周期性（每月）统计报废率，反馈给对应工程师改进 | PM |
| 5 | 电子件送回供应商做 RMA（Return Material Authorization） | 采购 |
| 6 | 塑料件按环保要求分类回收（ABS / 亚克力 / 硅胶） | 仓管 |

### 5.4 不合格品统计与改进

| 月份 | 装机数 | S1 故障 | S2 故障 | S3 故障 | S4 故障 | 总不合格率 |
|------|--------|---------|---------|---------|---------|-----------|
| ____ | ____ | ____ | ____ | ____ | ____ | ____ % |

**目标不合格率**：
- 试产期（前 50 台）：≤ 8%
- 量产期（>100 台）：≤ 3%

**当月不合格率 > 目标时**：
