## 一、产品概述

本产品为一款基于 ESP32-C3 Mini 的桌面智能鱼缸控制系统，通过本地局域网 Web 界面实现远程控制，具备水泵循环、LED 灯光、舵机喂食、温度监测、OLED 显示及加热棒控制等功能。

## 三、电路原理图详细说明

### 3.1 电源模块

#### 3.1.1 USB输入与保护

```
USB 5V输入
     │
     ├──→ TVS二极管 (SMBJ5.0A) ── 过压保护
     │
      └──→ 自恢复保险丝 (1A) ── 过流保护
              │
              └──→ 主电源分配
```

**电路说明：**
- USB接口（**Type-C**，16Pin 贴片，已锁定，**不采用 Micro-B**）输入5V供电
- TVS二极管(SMBJ5.0A)提供ESD和浪涌保护
- 自恢复保险丝(PPTC 1A)防止短路损坏

#### 3.1.2 电源分配

```
USB 5V
     │
     ├──→ VBUS ──→ 负载总供电 (水泵/舵机/LED/继电器)
     │
     └──→ AMS1117-3.3V LDO ──→ ESP32 3.3V供电
              │                    │
              │                    └──→ 外设3.3V (DS18B20等)
              │
              └──→ 输入滤波电容 C1 (10μF) + C2 (100nF)
                   输出滤波电容 C3 (10μF) + C4 (100nF)
```

**关键器件：**
- LDO芯片：AMS1117-3.3V（最大输出电流1A）
- 输入电容：C1=10μF(电解)+C2=100nF(陶瓷)
- 输出电容：C3=10μF(电解)+C4=100nF(陶瓷)

> **电容用途分类说明**：本项 10μF **专供 LDO 输入/输出滤波**；水泵/舵机/灯带使用的 1000μF 大电容见 §3.5/§3.6/§3.7，与 LDO 10μF **不可混用**（容量/耐压/位置均不同）。
- 输出电流需求：ESP32-C3峰值约500mA + 外设

**设计要点：**
- AMS1117需要足够散热，必要时加焊盘
- 输入输出电容尽量靠近芯片引脚放置
- 5V与3.3V地平面共地

### 3.2 主控模块 (ESP32-C3 Mini)

#### 3.2.1 最小系统电路

```
ESP32-C3 Mini
├── VDD (3.3V) ◄── 来自AMS1117-3.3V
├── GND ◄── 共地
├── USB D+ ◄── USB数据线 (烧录/调试用)
├── USB D- ◄── USB数据线
├── EN ◄── 10K上拉 + 100nF电容去耦
└── GPIO0/1/2/3/4/5/6 ◄── 功能引脚
```

**设计要点：**
- ESP32-C3 Mini为模块化设计，已内置晶振和flash
- EN引脚上拉100K电阻到3.3V，确保复位正常
- USB D+/D-预留用于烧录（也可用于串口调试）
- 所有GPIO支持GPIO中断功能

### 3.3 I2C显示模块 (OLED SSD1306)

#### 3.3.1 电路连接

```
ESP32-C3          OLED模块 (0.66寸 SSD1306)
GPIO0 (SDA) ──────── SDA
GPIO1 (SCL) ──────── SCL
3.3V        ──────── VCC
GND         ──────── GND
```

> OLED 实际 I2C 接线：SDA→GPIO0, SCL→GPIO1（按 PCB 布线）

**电路说明：**
- I2C地址：0x3C（默认）
- I2C速率：400KHz（快速模式）
- 无需外部上拉电阻（模块已内置）

**设计要点：**
- SDA/SCL走线尽量短，减少寄生电容
- 建议在SDA/SCL线上串联33Ω电阻（可选，抗干扰）
- OLED模块布线预留可插拔接口

---

### 3.4 温度监测模块 (DS18B20)

#### 3.4.1 电路连接

```
ESP32-C3                    DS18B20防水探头
GPIO7 ──── 4.7KΩ上拉 ────── DQ (数据线)
3.3V    ─────────────────── VDD (供电)
GND     ─────────────────── GND
```

**电路说明：**
- 采用寄生供电模式或正常供电模式（推荐正常供电）
- 4.7KΩ上拉电阻必须接在GPIO7与3.3V之间
- 数据线DQ连接到GPIO7

> **GPIO选型说明：** DS18B20使用GPIO7而非GPIO2，因为GPIO2是ESP32-C3的strapping引脚，上电时电平会影响启动模式（Boot选择）。使用GPIO7可避免潜在的启动风险，确保系统稳定启动。

**设计要点：**
- 上拉电阻位置尽量靠近主控板端
- DS18B20的DQ线可延长至3米（建议使用屏蔽线）
- 防水探头线缆焊接处需做防水处理（热缩管）
- 建议在GPIO7增加100Ω串联电阻（保护IO口）

---

### 3.5 水泵控制模块 (继电器)

#### 3.5.1 电路连接

```
ESP32-C3                    继电器模块 (5V 低电平触发)
GPIO3 ────────────────────── IN (控制信号)
5V    ────────────────────── VCC (继电器线圈供电)
GND   ────────────────────── GND
                                    │
                                    ├─── COM ─── 电源输入
                                    ├─── NO  ──→ 水泵正极
                                    └─── NC  ──→ (预留)

水泵
水泵正极 ◄─── NO (常开)
水泵负极 ◄─── GND
```

**续流保护电路：**
```
继电器线圈两端
     │
     ├──→ 续流二极管 1N4007 (反向并联)
     │        │
     │        └──→ 阳极接GND，阴极接5V
     │
     └──→ 吸收电容 100nF (可选)
```

**电路说明：**
- 继电器为低电平触发：GPIO3输出低电平时继电器吸合
- 续流二极管1N4007用于吸收继电器线圈关断时的反向电动势
- 水泵供电5V，最大电流约200mA

**滤波电容：**
```
5V总线 ────→ 1000μF电解电容 ◄─── GND
              (水泵供电滤波)
```

**设计要点：**
- 续流二极管必须反向并联在继电器线圈两端
- 二极管方向：阳极接低电位，阴极接高电位
- 水泵和舵机共用电容滤波
- 继电器触点建议使用常开(NO)配置

---

### 3.6 LED照明模块 (WS2812B)

#### 3.6.1 电路连接

```
ESP32-C3          WS2812B灯带         WS2812B灯带
GPIO5 ─────────── DI (数据输入) ──── DO (级联输出)
5V    ──────────────── VCC ──────────── VCC
GND   ──────────────── GND ──────────── GND
```

**电路说明：**
- WS2812B为单线协议，级联控制
- 数据线DI接GPIO5，DO连接到下一级灯珠
- 每个灯珠工作电流约60mA（全亮时）

**设计要点：**
- 灯带供电必须充足（每颗灯珠60mA）
- 建议在灯带电源入口加1000μF滤波电容
- 数据线串联电阻220Ω~470Ω（保护IO）
- 灯带长度建议不超过30颗灯珠（5V供电限制）
- 走线采用双绞线，减少信号干扰

---

### 3.7 舵机喂食模块 (SG90 9g)

#### 3.7.1 电路连接

```
ESP32-C3          舵机 (SG90 9g)
GPIO4 ──────────── PWM控制线 (橙/黄线)
5V    ──────────── VCC (红线)
GND   ──────────── GND (棕线)

5V总线 ────→ 1000μF电解电容 ◄─── GND
              (舵机供电滤波)
```

**电路说明：**
- SG90工作电压：4.8V~6V
- PWM控制信号：50Hz，脉宽1ms~2ms
  - 1ms (0°) / 1.5ms (90°) / 2ms (180°)
- 舵机堵转电流约250mA

**设计要点：**
- 舵机单独供电时需要充足电流储备
- PWM信号线长度尽量短（<30cm）
- 舵机与主控共地
- 可选：PWM线上串联100Ω电阻（保护GPIO）

### 3.8 加热棒控制接口 (预留)

#### 3.8.1 电路连接

```
ESP32-C3                    光耦隔离模块                    继电器模块
GPIO6 ──────→ 220Ω ──→ PC817 IN ── OUT ──→ 继电器IN     │
5V    ──────────────────── VCC                             │
GND   ──────────────────── GND ────────────────────────────┤
                                                              │
                                                              ├─── COM ─── 电源输入 (AC)
                                                              ├─── NO  ──→ 加热棒
                                                              └─── NC  ──→ (预留)

加热棒接线端子
```

> **安全警告：** 加热棒使用AC 220V供电，属于危险电压！必须使用光耦进行强弱电隔离，确保人身安全。

**电路说明：**
- **光耦隔离（必须）：** 使用PC817或其他光耦将ESP32的低压控制电路与220V强电侧完全隔离
- 光耦输入端串联220Ω限流电阻（LED正向电流约20mA）
- 光耦输出端控制继电器模块
- 继电器使用交流触点（AC 5A/250VAC以上）

**推荐方案：**

```
方案一：光耦 + 继电器模块（推荐）
├── PC817 光耦隔离
├── 5V直流继电器模块（线圈5V，触点AC 10A）
└── 适用于标准配置

方案二：固态继电器SSR（可选）
├── 直接由GPIO控制
├── 无机械触点，寿命更长
└── 需选型AC-SSR，控制电压匹配

方案三：光耦 + 功率开关芯片（高级）
├── 光耦隔离 + 分立功率器件
└── 适用于定制设计
```

**设计要点：**
- 光耦输入与输出之间必须有足够的隔离电压（≥1500V）
- 220V强电布线必须与低压电路保持足够间距（≥3mm）
- AC侧必须串联保险丝（1A~2A）
- 强电部分使用专用的安全认证接线端子
- 建议增加TVS二极管（AC侧）做浪涌保护
- 整体设计需符合电气安全标准

**强电安全检查清单：**
```
□ 光耦隔离确认（PC817或等效）
□ 隔离电压 ≥ 1500V AC
□ 继电器触点额定电流 ≥ 加热棒额定电流2倍
□ AC侧串联保险丝
□ 强弱电物理隔离距离 ≥ 3mm
□ 强电走线有明显标识
□ 接地保护措施到位
```

## 六、设计要点与注意事项

### 6.0 GPIO选型指南

> **ESP32-C3 GPIO使用注意事项**

| GPIO | 特殊功能 | 风险说明 | 推荐用途 |
|------|----------|----------|----------|
| GPIO0 | Strapping引脚 | 上电电平影响Boot模式 | 谨慎使用/避免使用 |
| GPIO1 | Strapping引脚 | 上电电平影响Flash电压 | 谨慎使用/避免使用 |
| GPIO2 | Strapping引脚 | 上电电平影响启动调试 | **❌ 历史错误（v1.0 曾用作 DS18B20，v1.1 已替换为 GPIO7）** |
| GPIO3 | Strapping引脚 | 上电电平影响ROM日志 | 谨慎使用 |
| GPIO4 | 普通GPIO | 无特殊限制 | 推荐使用 |
| GPIO5 | 普通GPIO | 无特殊限制 | 推荐使用 |
| GPIO6 | 普通GPIO | 无特殊限制 | 推荐使用 |
| GPIO7 | 普通GPIO | 无特殊限制 | **推荐用于DS18B20✓** |
| GPIO8 | 普通GPIO | 无特殊限制 | 推荐使用 |
| GPIO9 | 普通GPIO | 无特殊限制 | 推荐使用 |
| GPIO18 | 普通GPIO | 无特殊限制 | 推荐使用 |
| GPIO19 | 普通GPIO | USB D- | USB功能 |
| GPIO20 | 普通GPIO | USB D+ | USB功能 |
| GPIO21 | 普通GPIO | 无特殊限制 | 推荐使用 |

**Strapping引脚说明：**
- ESP32-C3的GPIO0~GPIO3在芯片上电时作为Strapping引脚，读取内部熔丝状态
- 这些引脚在启动瞬间的电平会影响芯片行为
- **推荐做法：** 上电后这些引脚可以正常使用，但应避免在上电时产生不确定电平
- **本设计选择GPIO7作为DS18B20数据线**，完全避免Strapping引脚风险

### 6.1 电源设计要点

1. **USB供电电流评估**
   - USB 2.0标准供电能力：500mA
   - USB 3.0标准供电能力：900mA
   - 建议使用5V/2A充电头确保供电充足

2. **负载电流预算**
   | 负载 | 工作电流 | 峰值电流 |
   |------|---------|---------|
   | ESP32-C3 Mini | 70mA | 500mA |
    | WS2812B (5颗) | 300mA | 300mA |
    | 水泵 | 200mA | 300mA |
    | 舵机 | 100mA | 250mA |
    | 继电器线圈 | 70mA | - |
    | OLED | 20mA | - |
    | **合计** | **760mA** | **1050mA** |

3. **建议**
   - 正常工作时避免所有负载同时最大功率运行
   - WS2812B限流：可通过程序控制亮度或减少灯珠数量
   - 可选增加USB限流保护芯片

### 6.2 继电器设计注意事项

1. **继电器选型**
   - 水泵：5V/10A DC继电器
   - 加热棒：5V/10A AC继电器（需交流触点）

2. **续流二极管必须接**
   - 位置：反向并联在继电器线圈两端
   - 方向：阳极接GND，阴极接VCC
   - 作用：吸收线圈关断时的反向电动势

3. **防止误动作**
   - GPIO初始化时设为高电平（防止继电器意外吸合）
   - 使用低电平触发继电器模块

### 6.3 布线注意事项

1. **电源线布线**
   - 5V主电源线宽：建议0.5mm以上（电流2A）
   - 3.3V电源线宽：建议0.3mm以上
   - GND铺铜：保证足够的接地面积

2. **信号线布线**
   - WS2812B数据线：串联220Ω电阻，位于主控端
   - DS18B20数据线：4.7KΩ上拉电阻位于主控端
   - 舵机PWM线：尽量短且远离电源线

3. **强弱电隔离**
   - 220V加热棒部分与低压电路物理隔离
   - 使用光耦隔离（可选，提高安全性）

### 6.4 温度传感器注意事项

1. **DS18B20使用**
   - 探头需放置于鱼缸水体中央位置
   - 线缆焊接处热缩管防水处理
   - 避免放置于加热棒正上方（局部温度过高）

2. **温度精度**
   - DS18B20精度：±0.5°C (-10°C~85°C)
   - 分辨率可设置：9/10/11/12位

### 6.5 OLED显示注意事项

1. **I2C地址**
   - 默认地址：0x3C
   - 如需两个OLED：另一个地址0x3D

2. **显示内容规划**
   - 温度显示
   - 工作状态（水泵/LED/喂食）
   - WiFi状态
   - 时间显示（可选）

### 7.4 常见故障排查

| 故障现象 | 可能原因 | 解决方法 |
|----------|----------|----------|
| 主控不启动 | 电源问题/焊接问题 | 检查3.3V供电/重新焊接 |
| OLED不显示 | I2C地址错误/接线错误 | 检查接线/GPIO0/GPIO1 或 I2C 地址（ESP32-C3 无 A4/A5） |
| 温度读取失败 | 4.7K上拉缺失/接线错误 | 检查GPIO7上拉电阻 |
| LED不亮 | 数据线串联电阻/供电问题 | 检查220Ω电阻/5V供电 |
| 继电器不动作 | 控制信号反了/供电不足 | 检查GPIO3/5V供电 |
| 舵机不转 | PWM信号不对/供电不足 | 检查GPIO4 PWM/5V供电 |
