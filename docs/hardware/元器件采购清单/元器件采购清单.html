六、采购渠道建议

🛒 淘宝 — 最全最快

适合：成品模块类（ESP32、OLED、传感器、舵机、水泵、LED灯条、继电器、亚克力板、3D打印件、耗材）

技巧：

  • 优先选「天猫店」或「销量高」的店铺，减少踩坑
  • ESP32-C3 建议选带「原装芯片」标签的，避免买到仿制芯片
  • 水泵/舵机选带「真实买家秀」确认静音效果的

    • 🏭 立创商城 — 电子元器件原装正品

    适合：降压芯片、电阻、电容、保险丝、TVS二极管、续流二极管

    技巧：

  • 注册新用户首单有折扣

  • 部分物料 1件起购，适合小批量补货

    九、注意事项

  • ESP32-C3 确认引脚间距：Mini版常见有 2.54mm（面包板友好）和邮票孔两种，选错了会导致无法直插焊接
  • 水泵供电隔离：水泵和主控建议分开供电（主控 5V USB，水泵外接 5V 电源），防止电机干扰 WiFi 信号
  • OLED 屏幕 I2C 地址：SSD1306 默认地址 0x3C，部分模块是 0x78，提前确认避免调试走弯路
  • WS2812B 防水灯条：5V 供电，每颗灯珠最大 60mA，10cm（大约 3 颗）合计最大电流约 180mA，确保 USB 供电够用
  • DS18B20 总线需要上拉电阻：数据线与 VCC 之间需接 4.7KΩ 上拉电阻，ESP32-C3 内部无上拉需外置
