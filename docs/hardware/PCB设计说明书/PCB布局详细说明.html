    四、布线设计规范

    4.1 线宽与电流关系

    信号类型线宽层载流能力用途
    -------------------------------------
    5V电源0.5mmTop/Bottom~800mAUSB输入、继电器
    3.3V电源0.3mmTop/Bottom~500mAMCU、传感器
    GND铺铜铺铜Top/Bottom-完整地平面
    信号线0.2mmTop/Bottom-GPIO、控制

    4.2 走线规则

    差分信号（I2C）：

  • SDA/SCL走线平行，间距0.3mm
  • 串联电阻靠近主控端
  • 避免与高频信号平行

    • 继电器驱动：

  • 线圈驱动线宽0.3mm
  • 续流二极管紧贴继电器引脚
  • 强弱电间距≥2mm

    • 敏感信号（DS18B20）：

  • 单总线走线尽量短
  • 远离电源干扰源
  • 上拉电阻靠近传感器端

    5.4 嘉立创SMT下单流程

  • 访问嘉立创官网 → 进入SMT下单页面
  • 上传Gerber文件 → 自动解析PCB信息
  • 上传BOM文件 → 系统匹配元器件
  • 确认物料 → 选择原厂原牌/替代料
  • 上传坐标文件 → 确认元器件位置
  • 审核PCBA → 3D预览确认
  • 提交订单 → 等待生产

    • 5.5 特殊元器件说明

    元器件处理方式注意事项
    ----------------------------
    ESP32-C3 Mini需要 Gerber 手动定位提供精确坐标文件
    USB Type-C标准SMD确保焊盘开窗
    继电器SMD带引脚引脚需要上锡
    安装孔NPTH（非金属化）避开铺铜

    六、电气安全注意事项

    6.1 强弱电隔离

  • 5V/3.3V走线与继电器端子保持≥2mm间距
  • 继电器输出端（强电）走底层，避开顶层敏感信号
  • 隔离槽宽度≥1mm

    • 6.2 防护措施

  • DS18B20接口增加TVS二极管防护
  • USB输入增加自恢复保险丝（500mA）
  • 继电器线圈并联续流二极管

    • 6.3 散热设计

  • AMS1117背部铺铜并打过孔散热
  • 继电器区域保持通风
  • 大电流走线加宽或铺铜
