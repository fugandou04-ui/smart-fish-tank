## 1. 产品概述

- **产品名称**: 桌面智能鱼缸
- **外形尺寸**: 15×15×15cm
- **适用对象**: 小型鱼类/虾/螺
- **主控芯片**: ESP32-C3 Mini（邮票孔贴片封装）
- **供电方式**: USB 5V 输入，用户自备充电头
- **通信方式**: 本地局域网 Web 控制

## 6. 布线策略

### 6.1 走线宽度设计

| 线路类型 | 线宽 | 载流能力 | 用途 |
|----------|------|----------|------|
| 5V 主电源 | 0.5mm | ~1A | USB 输入、电源主干 |
| 3.3V 电源 | 0.3mm | ~500mA | 主控供电、传感器 |
| 地线 | 铺铜 | - | 铺铜连接各 GND |
| 信号线 | 0.2mm | - | GPIO、I2C、PWM |

### 6.2 分区布局原则

```
+------------------------------------------+
|              弱电信号区                   |
|   [OLED]  [DS18B20]  [WS2812B]           |
|                                          |
|            +----------+                  |
|            | ESP32-C3 |                  |
|            |   Mini   |                  |
|            +----------+                  |
|                                          |
|   [舵机]                              [继电器]|
|              强电控制区                   |
+------------------------------------------+
```

**分区说明**:
- **弱电区**（左上）：OLED、DS18B20、WS2812B —— 抗干扰要求高
- **主控区**（中央）：ESP32-C3 Mini —— 信号交汇点
- **强电区**（右侧）：继电器、舵机接口 —— 继电器线圈会产生干扰

### 6.3 关键布线要点

#### 电源布线
1. USB 5V → 保险丝 → TVS → 滤波电容 → LDO
2. LDO 输出 3.3V → 主控及弱电元件
3. 5V 和 3.3V 分别铺铜，大面积铺铜散热
4. 每个 IC 的 VCC 引脚放置 100nF 退耦电容

#### 信号线布线
1. I2C（SDA/SCL）走线平行等距，避免跨越高速信号
2. DS18B20 数据线预留 4.7K 上拉电阻位置（靠近主控端）
3. WS2812B 数据线尽量短，必要时加 33R 串联电阻
4. 舵机 PWM 线加 10K 下拉电阻，防止开机误动作

#### 继电器布线
1. 继电器控制线（GPIO3、GPIO6）与信号线保持 3mm 以上间距
2. 继电器输出端与主控区域物理隔离
3. 继电器线圈并联续流二极管（1N4007）

#### 接地策略
1. 模拟地（DS18B20）和数字地通过单点连接
2. 继电器地与主控地隔离，减少干扰
3. 安装孔与地铺铜连接，作为屏蔽接地

## 8. 注意事项

### 8.1 电气安全
- 强电区域（继电器、水泵、加热棒）与弱电区域保持物理隔离
- 继电器输出端走线远离信号线，防止干扰
- USB 输入端加 TVS 保护，防止静电损伤

### 8.2 信号完整性
- I2C 总线走线长度不超过 10cm
- 高速信号（WS2812B）避免直角走线，使用 45 度或圆弧过渡
- 敏感信号线（DS18B20）远离继电器和大电流走线

### 8.3 PCB 可制造性
- 器件间距大于 0.3mm，方便贴片
- 邮票孔边缘留 0.5mm 工艺边
- SMD 元件统一采用 0805 封装以上，方便手工焊接调试

### 8.4 热设计
- LDO 并联 22uF 电容帮助散热
- 大电流走线铺铜加锡，增加载流能力
- 继电器模块发热较大，布局时注意周围通风
