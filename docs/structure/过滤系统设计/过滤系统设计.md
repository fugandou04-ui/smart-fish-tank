# 智能鱼缸过滤系统设计

> **项目**: 智能鱼缸  
> **缸体尺寸**: 15 × 15 × 15 cm（水量约 2.5 L）  
> **水泵**: 9025型 5V 静音潜水泵（建议流量 200–300 L/H）  
> **目标生物**: 小型鱼类 / 虾 / 螺  
> **版本**: v1.0  
> **日期**: 2026-05-21

### 水路流程

```
缸内水体
  ↓ [吸水口带初级过滤棉]
潜水泵（9025型 5V）
  ↓ [加压送水]
进水管道 → 过滤盒进水口
  ↓
第1层：毛刷/生化棉（物理过滤 + 初级生化）
  ↓
透水隔板（0.5mm微孔）
  ↓
第2层：陶瓷环（生化过滤，培菌）
  ↓
出水嘴 → 瀑布式回流 → 缸内
```

## 三、流量计算

### 3.1 基本参数

| 参数 | 数值 |
|------|------|
| 缸体水量 | 2.5 L |
| 目标循环次数 | 8–12 次/小时 |
| 所需理论流量 | 20–30 L/H |
| 实际水泵标称流量 | 200 L/H（5V工况约 100–150 L/H） |
| 沿程损失（软管+弯头） | 约 15–25% |
| 过滤介质阻力 | 约 10–20% |
| **有效出水流量** | **约 60–90 L/H（≈25–36次/小时）** |

> **说明**: 9025型水泵标称流量通常在 12V 满压工况测得。5V 低压供电时，流量约为标称的 50–75%，即 **100–150 L/H**。考虑管路沿程损失（软管 φ4/6mm × 15cm + 2个弯头，约 20%）及过滤介质阻力（约 15%），有效出水流量约 **60–90 L/H**，对应水循环 **25–36 次/小时**，略偏高，建议通过阀门或 PWM 调速控制在 8–12 次/小时。

### 3.2 流量调节方案

| 方案 | 实现方式 | 优缺点 |
|------|----------|--------|
| PWM 调速 | 5V PWM 信号控制水泵转速 | 精确可调，需控制器支持 |
| 球阀调节 | 出水管路串联微型球阀 | 简单可靠，无法精确量化 |
| 分流回路 | 一路过滤盒 + 一路回流旁路 | 保护水泵，减少无效循环 |

**推荐**: PWM 调速（与智能控制系统集成），配合液位传感器闭环控制。

### 3.3 液位差计算

```
泵出口 → 过滤盒底部（垂直高度约 5 cm）
过滤盒顶部 → 出水口（垂直高度约 3 cm）
总扬程 ≈ 8 cm
9025型 5V 扬程：约 50–80 cmH₂O ✓（满足要求）
```

## 五、清洗维护说明

### 5.1 维护周期

| 项目 | 清洗周期 | 更换周期 | 说明 |
|------|----------|----------|------|
| 吸水口过滤棉 | 每 1–2 周 | 每 1–2 月 | 堵塞后立即清洗 |
| 生化棉层 | 每 2–4 周（冲洗） | 每 3–6 月 | 用原缸水轻揉清洗 |
| 陶瓷环 | 每 3–6 月（冲洗） | 每 1–2 年 | 切勿用自来水，会杀菌 |
| 换水 | 每周 20–30% | —— | 用换水阀引流 |
| 软管清洁 | 每 2–3 月 | 有老化迹象时更换 | 用缸水冲洗 |

### 5.2 清洗步骤

#### A. 日常清洗（生化棉）

1. 关闭水泵电源
2. 拆下过滤盒盒盖（按压卡扣或取下磁吸盖）
3. 抽出生化棉托盘，用缸内原水轻轻揉洗，**禁止使用自来水**
4. 清洗后放回原位，盖上盒盖
5. 重新开启水泵

#### B. 深度清洗（陶瓷环）

1. 关闭水泵，排空过滤盒内水体
2. 取出陶瓷环托盘
3. 将陶瓷环放入一个容器中，用**原缸水或除氯自来水快速漂洗**
4. **禁止搓洗**，轻晃即可，以免破坏多孔结构
5. 若硝化系统崩解（换水后水质浑浊），补充一瓶硝化细菌菌液
6. 晾干 5–10 分钟后复位

#### C. 换水操作

1. 打开换水阀（串联在出水回路或单独布置）
2. 引流至接水容器
3. 每次换水 20–30%（约 500–750 mL）
4. 换水后补充等量等温（同温）新水
5. 关闭换水阀

### 5.3 维护注意事项

- **禁止使用肥皂、洗洁精**等任何化学清洗剂
- 每次清洗的介质不超过总量的 **1/2**，保留一半旧介质以维持菌群
- 清洗后若水体浑浊，为正常现象（菌群重建期），约 24–48 小时自愈
- 过滤盒建议固定在缸壁内侧，可用磁吸固定器或 3M 胶贴
- 冬季低温（<18℃）时，菌群活性下降，可适当减少喂食量

## 六、补充说明

### 6.1 与智能控制系统的接口

| 接口 | 说明 |
|------|------|
| 水泵电源 | 5V PWM 控制，支持转速 0–100% 调节 |
| 液位传感器 | 监测缸内液位，低液位时自动关泵保护 |
| 水质传感器（可选） | pH / 氨氮 / 温度传感器，联动调节循环频率 |

### 6.2 安全保护

- **干转保护**: 液位低于吸水口时，液位传感器触发关泵
- **堵转保护**: 过滤棉堵塞导致流量异常时，控制器检测并报警
- **过流保护**: 水泵堵转电流 > 0.25A 时自动断电
