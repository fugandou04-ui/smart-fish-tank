# 智能鱼缸过滤系统设计

> **项目**：智能鱼缸（v2.0 架构）
> **缸体尺寸**：15 × 15 × 15 cm（水量约 2.5 L）
> **水泵**：9025 型 5V 静音潜水泵（位于**底座内**），建议流量 200–300 L/H
> **过滤盒**：背滤式（缸内后板内侧，竖立式 80×40×100 mm）
> **目标生物**：小型鱼类 / 虾 / 螺
> **版本**：**v2.0**（与结构设计说明书 v2.0 同步）
> **日期**：2026-06-06
> **基于**：`结构设计说明书/结构设计说明书.md` v2.0（2026-05-28）

### 水路流程（v2.0）

```
缸内水体
  ↓ [重力/扩散]
背滤盒（前置物理过滤，过滤海绵）
  ↓ [φ8 mm 出水口]
硅胶软管（内 φ4 × 外 φ6 mm，长约 200 mm）
  ↓ [穿过底座上盖 φ10 通孔]
底座内水泵（9025 型 5V）
  ↓ [加压送水]
出水软管（内 φ4 × 外 φ6 mm，长约 150 mm）
  ↓ [快插接头连接]
回归缸内（瀑布式回流）
```

> **v2.0 核心变更**：水路由"缸内水泵 → 底座旁过滤盒 → 缸内"改为"缸内背滤盒（前置）→ 底座水泵 → 缸内"。水泵位置由缸内底角移至底座内，过滤盒位置由底座旁移至缸内后板内侧。

## 二、过滤盒结构设计（v2.0 背滤式）

### 2.1 过滤盒外形（v2.0）

| 参数 | v1.0 旧值 | **v2.0 新值** |
|------|---------|-------------|
| 外形尺寸 | 80 × 40 × 30 mm | **80 × 40 × 100 mm**（竖立式，高度由 30 改为 100） |
| 内腔尺寸 | 76 × 36 × 28 mm | **78 × 38 × 98 mm** |
| 位置 | 底座旁（卡扣固定在底座上盖） | **缸内后板内侧**（挂扣 + 支架，可从上方抽出） |
| 材料 | PETG / PLA / ABS | **ABS（3D 打印）/ PP（注塑）** |
| 壁厚 | 2 mm | 2 mm |
| 卡扣 / 挂扣 | 4 个卡扣（盒体两侧） | **2 条挂扣**（后面板内侧支架） |
| 过滤介质 | 毛刷 + 陶瓷环（多腔） | **仅物理过滤海绵**（单腔） |

### 2.2 内部结构（v2.0 简化）

> **v2.0 重大变更：取消多腔设计，简化为单腔 + 过滤海绵。**

```
正视图（80×100 mm，竖立）:

┌──────────────────────┐
│      提手 15×8mm      │  ← 顶面
├──────────────────────┤
│                      │
│                      │
│    过滤海绵           │  ← 单腔物理过滤
│   (75×35×95mm)      │
│                      │
│                      │
│                      │
├──────────────────────┤
│   8 条进水缝隙        │  ← 前侧
│   (宽 2mm)            │
├──────────────────────┤
│   φ8 出水口            │  ← 底面
└──────────────────────┘
```

| 区域 | 位置 | 设计 |
|------|------|------|
| 顶面 | 提手 | 宽 15mm，深 8mm，便于从上方抽出 |
| 前侧 | 进水缝隙 | 宽 2mm × 8 条，缸内水由此进入 |
| 内部 | 过滤海绵 | 75×35×95mm 标准物理过滤海绵（v2.0 取消陶瓷环、生化棉、毛刷） |
| 底面 | 出水口 | φ8mm 通孔，连接至底座水泵吸水口 |
| 后侧 | 挂扣 | 2 条挂扣，与后面板内侧支架（5×100mm × 2 条）配合 |
| 两侧 | 轻量化孔 | 各 3 个 φ5mm 孔 |

### 2.3 可拆卸设计（v2.0）

- **背滤盒整体**：通过挂扣固定在缸内后板内侧支架上，可从缸口**直接向上抽出**（维护时先开缸盖）
- **过滤介质**：仅一块过滤海绵，抽出后用缸内原水轻揉清洗（**禁止用自来水**）
- **密封**：盒体接缝处粘贴硅胶密封条（耐温 -40℃~200℃）
- **取消盒盖**：v2.0 背滤盒顶面是提手（不是盒盖），无磁吸/卡扣式盒盖

### 2.4 过滤介质简化为仅物理过滤海绵

| v1.0 多腔介质 | v2.0 处理 |
|-------------|---------|
| 毛刷层 | **取消** |
| 生化棉 | **取消** |
| 陶瓷环 | **取消** |
| 透水隔板 | **取消** |
| —— | **仅保留物理过滤海绵**（75×35×95mm） |

> **设计理由**（来自 `优化要求.md`）：2.5L 小缸水体小，物理过滤足以维持水质稳定；取消生化过滤可大幅简化背滤盒结构和维护工作量。

## 三、流量计算（v2.0 重算）

### 3.1 基本参数

| 参数 | 数值 |
|------|------|
| 缸体水量 | 2.5 L |
| 目标循环次数 | 8–12 次/小时 |
| 所需理论流量 | 20–30 L/H |
| 实际水泵标称流量 | 200 L/H（5V 工况约 100–150 L/H） |
| 沿程损失（软管+弯头） | 约 20% |
| 过滤介质阻力（v2.0 仅 1 块海绵） | 约 5%（v2.0 比 v1.0 阻力更小） |
| **有效出水流量** | **约 80–110 L/H（≈32–44次/小时）** |

> v2.0 比 v1.0 阻力更小（取消陶瓷环、毛刷等多腔介质），有效流量更高。仍建议通过 PWM 调速控制在 8–12 次/小时。

### 3.2 扬程计算（v2.0 重算）

> **v1.0 扬程 ≈ 8 cm**（水泵在缸内底角，扬程低）  
> **v2.0 扬程 ≈ 15–20 cm**（水泵在底座，需将水从缸底抽到缸外再回缸内）

```
水泵出口（底座内）
   ↓
底座上盖 → 背滤盒（缸内）  垂直高度：底座高 48 + 缸体 50（背滤盒中部） ≈ 70-100 cm
   ↓
实际扬程主要消耗于：
  - 软管沿程损失：~3 cm
  - 弯头损失（2个）：~2 cm
  - 过滤海绵阻力：~3 cm
  - 重力提升：背滤盒出水口在缸底附近，水泵需提水 0~3 cm
合计实际扬程：约 10–15 cm

9025 型 5V 扬程：50–80 cmH₂O  ✓ 满足
```

### 3.3 流量调节方案

| 方案 | 实现方式 | 优缺点 |
|------|----------|--------|
| PWM 调速 | 5V PWM 信号控制水泵转速 | 精确可调，需控制器支持（**v2.0 推荐**）|
| 球阀调节 | 出水管路串联微型球阀 | 简单可靠，无法精确量化 |
| 分流回路 | 一路背滤盒 + 一路回流旁路 | 保护水泵，减少无效循环 |

**推荐**：PWM 调速（与智能控制系统集成），配合液位传感器闭环控制。

## 五、清洗维护说明（v2.0 重写）

### 5.1 维护周期

| 项目 | 清洗周期 | 更换周期 | 说明 |
|------|----------|----------|------|
| 背滤盒过滤海绵 | 每 1–2 周 | 每 1–2 月 | 堵塞后立即清洗 |
| 水泵吸水过滤棉 | 每 2–4 周 | 每 1–2 月 | 用缸水轻揉清洗 |
| 换水 | 每周 20–30% | —— | 直接倒出或用水泵抽出 |
| 软管清洁 | 每 2–3 月 | 有老化迹象时更换 | 用缸水冲洗 |

### 5.2 清洗步骤（v2.0 简化）

> **v2.0 重大变更**：维护从"拆盒盖 → 抽托盘"改为"开缸盖 → 从上方抽出背滤盒"。

#### A. 背滤盒清洗（v2.0 标准流程）

1. 关闭水泵电源
2. **打开缸盖**（向上提起缸盖）
3. **从上方抽出背滤盒**（握住提手，垂直向上拉出）
4. 取出过滤海绵，用缸内原水轻轻揉洗（**禁止使用自来水**）
5. 滤盒内壁用软毛刷轻刷
6. 装回过滤海绵，将背滤盒**从上向下**对准后板支架推入
7. 盖回缸盖（确认密封圈压紧）
8. 重新开启水泵

#### B. 水泵清理

1. 关闭水泵电源
2. 拧开底座上盖的 4 颗 M3 螺钉
3. 拧开快插接头，取出水泵固定座
4. 清理水泵吸水过滤棉
5. 复位安装

#### C. 换水操作（v2.0 简化）

1. 打开缸盖，拔掉喂食器壳
2. 直接倒出或用水泵抽出
3. 每次换水 20–30%（约 500–750 mL）
4. 换水后补充等量等温（同温）新水
5. 盖回缸盖

> v2.0 **取消** v1.0 的"换水阀"接口（v2.0 改为直接倒出或用水泵抽出）。

### 5.3 维护注意事项

- **禁止使用肥皂、洗洁精**等任何化学清洗剂
- **v2.0 仅有 1 块海绵**，清洗时不存在"保留一半旧介质"的问题（v1.0 提示已废止）
- 清洗后若水体浑浊，为正常现象（碎屑扰动），约 24–48 小时自愈
- 冬季低温（<18℃）时，可适当减少喂食量
- 背滤盒每 3–6 月可整体取出做一次深度清洗

## 六、补充说明

### 6.1 与智能控制系统的接口

| 接口 | 说明 |
|------|------|
| 水泵电源 | 5V PWM 控制，支持转速 0–100% 调节（**v2.0 水泵位置变更对 PWM 控制无影响**）|
| 液位传感器 | 监测缸内液位，低液位时自动关泵保护 |
| 水质传感器（可选）| pH / 氨氮 / 温度传感器，联动调节循环频率 |

### 6.2 安全保护

- **干转保护**：液位低于吸水口时，液位传感器触发关泵
- **堵转保护**：过滤海绵堵塞导致流量异常时，控制器检测并报警
- **过流保护**：水泵堵转电流 > 0.25A 时自动断电

### 6.3 v2.0 架构优势

| 维度 | v1.0 旧架构 | v2.0 新架构 |
|------|-----------|-----------|
| 维护频率 | 高（多介质维护复杂） | 低（仅 1 块海绵） |
| 维护工具 | 需拆盒盖 | **徒手**（开缸盖抽出） |
| 防水风险点 | 多（底座旁过滤盒接口多） | 少（水路集中在底座） |
| 水泵位置 | 缸内（噪音大） | **底座内**（隔音好） |
| 水泵散热 | 一般 | 底座空气对流，散热好 |
| 过滤效果 | 多级（物理+生化）| 物理（适合 2.5L 小缸）|
