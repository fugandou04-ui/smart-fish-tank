## 一、产品概述与设计目标

### 1.1 产品定位

桌面智能鱼缸是一款面向普通养鱼爱好者的智能水族产品，集成了水循环过滤、LED 照明、自动喂食、温度监测和 OLED 信息显示五大功能。缸体采用 15×15×15 cm 亚克力结构，总高度控制在 18 cm 以内，适合桌面摆放。

### 1.2 设计约束汇总

| 参数 | 数值 |
|------|------|
| 缸体外尺寸 | 150 × 150 × 150 mm |
| 总高度 | ≤ 180 mm |
| 底座面积 | 160 × 160 mm（比缸体每边大 5 mm） |
| 底座高度 | ≤ 50 mm |
| 亚克力壁厚 | 2 mm |
| 水容量 | 约 2.5 L |
| 水管内径 | 4 mm |
| 舵机轴孔 | 5 mm |
| PCB 定位孔 | 3 mm（直径） |

### 1.3 结构重组说明（v2.0 核心变更）

**优化前问题：**
- PCB 和电子元件置于底座内部，散热差、维护困难
- 过滤盒在底座内部，换水时需拆卸底座上盖
- 结构复杂，防水风险点多

**优化后方案：**
- 背滤盒移至缸内后板内侧（背滤式设计）
- 所有 PCB 和电子元件移至上盖上方（易于维护）
- 底座内仅保留水泵（结构简化）
- 喂食器 + PCB 在缸盖上方（模块化）

### 1.4 设计原则

- 所有结构件优先适配 FDM 3D 打印工艺，公差统一加放 **+0.2 mm**
- 后续注塑可沿用同款 3D 模型，仅需调整材料参数
- 优先选用 **ABS（3D 打印）/ PP（注塑）**，兼顾韧性与耐水
- 可拆卸设计覆盖所有需要维护的部件，换水无需工具
- 防水等级：底座外壳 IP54（泼溅防护），灯条 IP67

## 六、装配顺序

> 优化后的装配顺序：从上到下、从外到内、先电气后机械。

### Step 1 — PCB 预装（上盖上方）

1. **安装 PCB**：对准 4 个 φ3 mm 定位孔，放上定位柱后用 M3 螺钉固定
2. **焊接元器件**：OLED 屏、按键、舵机线、水泵线、温度探头线、LED 排线
3. **安装 OLED 屏幕**：嵌入上盖屏幕框，用少量导热硅胶固定
4. **安装按键**：插入 3 个按键，确认手感正常

### Step 2 — 底座内部预装（干燥环境）

1. **安装水泵固定座**：将 TPU 减震套套在水泵上，对准底座内腔凸台压入
2. **固定水泵**：用 M2.5 螺钉 4 颗固定水泵
3. **连接水管快接头**：在手柄环位置拧紧到水泵座上（进、出各 1 个）
4. **连接背滤盒出水管**：将硅胶管从底座上盖开孔穿过，连接至水泵进水口

### Step 3 — 安装底座上盖

1. **放置底座上盖**：对准四角的 M3 螺钉孔，放上盖体
2. **穿过水管**：将背滤盒出水管从底座上盖中央孔穿过
3. **固定螺钉**：用 M3 × 8 mm 沉头螺钉 4 颗拧紧（扭矩 0.3 N·m）
4. **连接线束**：舵机线、水泵线、OLED 排线、温度探头线分别接入 PCB

### Step 4 — 粘接缸体

> 注意：亚克力粘接需使用专用 **ABS 胶水** 或 **氯仿（CHCl₃）**，固化时间 24 h。

1. **粘接底板与侧板**：将 4 块侧板分别与底板粘接，用定位台阶保证垂直度
2. **粘接侧板间接缝**：四块侧板相互粘接形成方筒，确保 90° 角（用角尺校验）
3. **安装背滤盒**：将背滤盒挂扣对准后面板内侧支架，推入固定
4. **连接背滤盒出水管**：将软管连接至背滤盒底部出水口
5. **粘接顶盖密封条**：在底板顶面涂胶前，先安装密封法兰（宽 4 mm）

> ⚠️ **注意**：粘接完成后至少等待 **24 小时** 再注水测试，确保胶水完全固化。

### Step 5 — 安装缸盖与喂食系统

1. **粘接 O 形圈**：在缸盖喂食口法兰槽内放入 φ3 mm 硅胶圈
2. **安装 LED 固定座**：将灯条嵌入 V 形槽，压入缸盖 LED 槽，两端插入防水塞
3. **安装喂食器壳**：对准法兰面粘接到缸盖上（可用 ABS 胶水）
4. **安装舵机**：用 4 颗 M2 螺钉将舵机固定在喂食器壳顶部
5. **安装喂食转盘**：将转盘压入舵机轴，用少量 AB 胶固定

### Step 6 — 总装

1. **安装缸体**：将粘好的缸体从上方落入底座上盖的法兰槽，确认四边完全就位
2. **安装缸盖**：将缸盖卡扣扣入侧板顶端，确认密封圈压紧
3. **连接背滤盒出水管**：确认软管连接牢固，无脱落风险
4. **功能测试**：注水通电，测试水泵、灯、喂食舵机、OLED 显示、温度监测
5. **气密测试**：静置 24 h，检查各连接处无渗漏

### 维护拆卸顺序（换水/清理时）

> **优化后更简便！底座内只有水泵，维护更简单。**

1. **拔掉喂食器壳**（或打开缸盖）
2. **取出背滤盒** → 从上方抽出，清洗/更换海绵
3. **水泵清理** → 拧开快插接头，取出水泵固定座清理
4. **换水** → 直接倒出或用水泵抽出
