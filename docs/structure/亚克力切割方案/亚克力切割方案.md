## 5. 粘接工艺说明

### 5.1 粘接原理（v1.1 补充）

亚克力粘接有两种方式：
1. **溶剂粘接**：氯仿渗入材料表面，溶胀后固化粘合（强度高、美观）
2. **胶水粘接**：使用专用亚克力胶（操作容错率高）

> **v1.1 补充**：粘接前**必须确认前/后/侧板的开孔位置和方向**，避免装反。具体方向见 §1.1 侧板方向与开孔清单：
> - 前面板（A，φ8mm 孔）朝向 OLED 方向
> - 后面板（D，支架槽）朝向背滤盒安装位
> - 右侧板（B，φ6mm 孔）朝向底座侧壁水管方向
> - 左侧板（C，完整）朝向另一侧

### 5.2 推荐工艺流程

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   步骤1       │     │   步骤2       │     │   步骤3       │
│   清洁表面     │ ──► │   对齐固定     │ ──► │   涂胶粘接     │
└──────────────┘     └──────────────┘     └──────────────┘
       │                                         │
       ▼                                         ▼
┌──────────────┐                         ┌──────────────┐
│ 无水乙醇擦拭   │                         │ 固化处理      │
│ 去除油污灰尘   │                         │ 常温静置24h   │
└──────────────┘                         └──────────────┘
```

### 5.3 详细操作步骤

#### 步骤1：清洁
- 用无水乙醇擦拭所有待粘接边缘
- 佩戴手套，避免手指接触粘接面
- 确保表面干燥、无油污

#### 步骤2：对齐固定
- 使用夹具或胶带预先固定板材
- 确保 45° 斜角对齐紧密，缝隙 < 0.1mm
- 可使用直角治具辅助定位

#### 步骤3：涂胶
- 使用注射器或细毛刷蘸取氯仿
- 沿粘接缝均匀涂抹，量不宜过多
- 毛细作用会将胶水吸入缝隙

#### 步骤4：固化
- 轻微施压（夹具固定）
- 常温静置 24 小时
- 避免移动或震动

### 5.4 注意事项

| 事项 | 说明 |
|------|------|
| 安全防护 | 氯仿有毒，操作时佩戴口罩、手套，保持通风 |
| 胶量控制 | 少量多次，避免溢胶导致雾化痕迹 |
| 固化时间 | 初期固化 5-10min，完全固化 24h |
| 去除气泡 | 涂胶后轻敲震动，帮助气泡排出 |

### 5.5 质量检验

- [ ] 粘接缝透明，无明显白雾
- [ ] 缝隙 < 0.1mm（目视不可见）
- [ ] 结构强度：轻压不变形
- [ ] 防水测试：无渗漏
