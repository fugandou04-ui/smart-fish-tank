5. 粘接工艺说明

5.1 粘接原理

亚克力粘接有两种方式：

  • 溶剂粘接：氯仿渗入材料表面，溶胀后固化粘合（强度高、美观）
  • 胶水粘接：使用专用亚克力胶（操作容错率高）

    5.3 详细操作步骤

    步骤1：清洁

  • 用无水乙醇擦拭所有待粘接边缘
  • 佩戴手套，避免手指接触粘接面
  • 确保表面干燥、无油污

    • 步骤2：对齐固定

  • 使用夹具或胶带预先固定板材
  • 确保 45° 斜角对齐紧密，缝隙 < 0.1mm
  • 可使用直角治具辅助定位

    • 步骤3：涂胶

  • 使用注射器或细毛刷蘸取氯仿
  • 沿粘接缝均匀涂抹，量不宜过多
  • 毛细作用会将胶水吸入缝隙

    • 步骤4：固化

  • 轻微施压（夹具固定）
  • 常温静置 24 小时
  • 避免移动或震动

    • 5.4 注意事项

    事项说明
    ------------
    安全防护氯仿有毒，操作时佩戴口罩、手套，保持通风
    胶量控制少量多次，避免溢胶导致雾化痕迹
    固化时间初期固化 5-10min，完全固化 24h
    去除气泡涂胶后轻敲震动，帮助气泡排出

    5.5 质量检验

  • [ ] 粘接缝透明，无明显白雾
  • [ ] 缝隙 < 0.1mm（目视不可见）
  • [ ] 结构强度：轻压不变形
  • [ ] 防水测试：无渗漏
