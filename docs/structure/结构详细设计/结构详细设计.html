二、零件清单与设计要点

2.1 底座外壳

功能： 防水外壳，容纳电子PCB、元器件、接口

关键尺寸：

  • 外形尺寸：160×160×50mm
  • 内腔尺寸：130×130×40mm（用于PCB安装）
  • 壁厚：2.5mm
  • 底部厚度：3mm（加强）

    • 设计要点：

  • 外壳预留USB-C接口孔位（12×8mm），位于侧面
  • 预留OLED屏幕开口：35×12mm（位于外壳正面）
  • 预留按键孔：3个，直径5mm，间距10mm
  • 底部设计4个M3沉头螺钉孔（用于固定上盖）
  • 沉头孔深度：2mm，直径6mm
  • 外壳内部设计PCB定位柱4个（M3螺纹孔）
  • 定位柱高度：5mm，间距120×120mm

    • 配合关系：

  • 与底座上盖：卡扣+螺钉双固定
  • 与缸体底板：卡槽配合（深度5mm）

    • 材料选择： PLA（熔点220°C，强度好，成本低）

    2.2 底座上盖

    功能： 定位PCB，密封电子腔

    关键尺寸：

  • 外形尺寸：156×156×3mm
  • PCB定位孔：4个，直径3.2mm（3D公差）
  • PCB定位柱：4个，高度8mm，外径6mm，内径M3
  • 水泵接口：外径10mm，内径8mm
  • 舵机安装孔：20×20mm间距

    • 设计要点：

  • 上盖设计环形密封槽，槽宽3mm，深1.5mm
  • 密封槽用硅胶O型圈（内径130mm）密封
  • PCB固定螺钉：M3×8mm沉头螺钉
  • 预留舵机线走线槽：宽5mm，深2mm
  • 预留传感器线走线孔：直径3mm×2个

    • 配合关系：

  • 与底座外壳：M3螺钉×4固定，密封圈防水
  • 与PCB：定位柱定位，螺钉固定

    • 材料选择： PETG（耐温好，韧性好，适合密封件）

    2.3 缸体底板

    功能： 承接缸体重量，与底座卡槽配合

    关键尺寸：

  • 外形尺寸：154×154×3mm
  • 卡槽宽度：5mm（用于插入底座）
  • 卡槽深度：10mm
  • 中心开孔：用于水泵安装，直径20mm

    • 设计要点：

  • 底板四边设计卡槽，与亚克力缸体侧板粘接
  • 底板中心孔用于安装水泵固定座
  • 底板与底座外壳接触面设计防水密封圈槽
  • 密封圈槽宽度：4mm，深度：2mm
  • 底板材质与亚克力颜色一致（透明）

    • 配合关系：

  • 与亚克力侧板：粘接密封（UV胶或氯仿）
  • 与底座外壳：卡槽插入式配合

    • 材料选择： 亚克力板（2mm厚，透明）

    2.4 缸体侧板（×4）

    功能： 透明缸壁，观赏鱼缸

    关键尺寸：

  • 尺寸规格：
  • 前/后侧板：150×150mm（开喂食口）
  • 左/右侧板：150×150mm（完整）
  • 厚度：2mm
  • 喂食口尺寸：40×30mm（仅前侧板）

    • 设计要点：

  • 前侧板开喂食口（40×30mm），位于顶部边缘下20mm
  • 所有侧板边缘需进行倒角处理（0.5mm×45°）
  • 粘接面需磨砂处理（增加粘接强度）
  • 侧板与底板、顶盖粘接处设计0.5mm加强边
  • 侧板四角需45°切割拼角粘接

    • 配合关系：

  • 与缸体底板：粘接密封
  • 与缸盖：粘接密封
  • 侧板之间：45°角粘接拼角

    • 材料选择： 亚克力板（2mm厚，透明，透光率92%）

    2.5 缸盖

    功能： 封闭缸体顶部，开设喂食口

    关键尺寸：

  • 外形尺寸：154×154×3mm
  • 喂食口尺寸：50×40mm（带翻盖）
  • 翻盖铰链轴孔：直径2mm×2个
  • 密封边高度：5mm

    • 设计要点：

  • 缸盖边缘设计5mm密封边，插入侧板内
  • 喂食口设计铰链式翻盖（单独打印件）
  • 翻盖设计磁吸闭合（可选）或卡扣闭合
  • 喂食口周围设计防水密封槽（宽3mm）
  • 缸盖预留LED灯安装槽（宽8mm，深3mm）
  • 缸盖预留温度传感器线过孔（直径3mm）

    • 配合关系：

  • 与缸体侧板：粘接密封
  • 与翻盖：铰链连接
  • 与LED固定座：槽位配合

    • 材料选择： 亚克力板（2mm厚，透明）

    2.6 过滤盒

    功能： 容纳过滤海绵，可拆卸清洗

    关键尺寸：

  • 外形尺寸：80×40×30mm
  • 内腔尺寸：75×35×25mm
  • 进水口：直径8mm
  • 出水口：直径8mm
  • 固定卡扣：2个

    • 设计要点：

  • 过滤盒设计为抽屉式，可从侧面抽出
  • 内部放置过滤海绵（需适配尺寸）
  • 进水口连接水泵，出水口连接缸体
  • 设计卡扣结构固定在底座上盖
  • 过滤盒底部设计集污槽（深3mm）
  • 设计快拆结构，无需工具即可拆卸

    • 配合关系：

  • 与底座上盖：卡扣固定
  • 与水泵：水管快插连接（4mm内径）
  • 与缸体：水管连接

    • 材料选择： PLA（需打印支撑）

    2.7 水泵固定座

    功能： 固定水泵，减震防漏

    关键尺寸：

  • 外形尺寸：30×30×20mm
  • 水泵定位槽：25×25mm
  • 进水口：内径8mm，外径12mm
  • 出水口：内径4mm（快接头接口）
  • 安装孔：M3×4个

    • 设计要点：

  • 水泵固定座设计减震结构（硅胶垫或弹簧）
  • 进水口设计双重密封（O型圈+卡箍）
  • 出水口连接水管快接头（4mm内径）
  • 水泵固定座与底座上盖之间加硅胶减震垫
  • 减震垫厚度：3mm，硬度：50A
  • 设计防漏结构：进水口垂直朝上，避免虹吸

    • 配合关系：

  • 与底座上盖：螺钉固定（M3×4）
  • 与水泵：卡槽定位
  • 与水管快接头：插接+卡箍固定

    • 材料选择： PLA + 硅胶减震垫

    2.8 喂食器壳

    功能： 顶部开口，存放鱼食，落食通道

    关键尺寸：

  • 外形尺寸：50×50×25mm
  • 顶部开口：40×40mm
  • 底部落食口：直径8mm
  • 舵机安装位：20×20mm

    • 设计要点：

  • 喂食器壳设计为漏斗形，顶部大口便于加食
  • 顶部设计翻盖（与缸盖类似），防潮防尘
  • 底部落食口连接缸体内部
  • 内部设计转盘轴孔（直径5mm）
  • 舵机安装在壳体外部，通过轴驱动转盘
  • 设计鱼食观察窗（透明亚克力）

    • 配合关系：

  • 与缸盖：螺丝固定
  • 与喂食转盘：轴孔配合
  • 与舵机：固定座连接

    • 材料选择： PLA（主体）+ 亚克力（观察窗）

    2.9 喂食转盘

    功能： 承载鱼食，被舵机轴驱动旋转落食

    关键尺寸：

  • 直径：40mm
  • 厚度：3mm
  • 中心轴孔：直径5mm（与舵机轴配合）
  • 分格数：2格或4格
  • 格槽深度：5mm

    • 设计要点：

  • 转盘设计分格结构，确保每次喂食量可控
  • 建议2格设计，每格容量约1ml
  • 中心轴孔与舵机轴采用键槽配合（防打滑）
  • 转盘边缘设计限位块，防止旋转超程
  • 转盘直径略小于喂食器壳内径（间隙0.5mm）
  • 建议转盘设计自清洁斜坡，便于清理残留

    • 配合关系：

  • 与喂食器壳：轴孔定位，旋转自由
  • 与舵机轴：键槽或摩擦配合
  • 与鱼食：承载+落食导向

    • 材料选择： PLA（食品级可选）

    2.10 LED固定座

    功能： 固定LED灯带，导光，防水

    关键尺寸：

  • 安装槽宽度：8mm（适配WS2812B灯带）
  • 固定座高度：5mm
  • 长度：可根据需要裁剪
  • 安装孔：M2×间距20mm

    • 设计要点：

  • LED固定座设计为U型槽，嵌入灯带
  • 固定座设计导光结构（亚克力材质）
  • 固定座设计防水密封边（用于嵌入缸盖）
  • 灯带嵌入式安装，露出发光面
  • 固定座设计走线槽，隐藏LED数据线
  • 设计散热结构（鳍片式，增加散热面积）

    • 配合关系：

  • 与缸盖：嵌入密封槽
  • 与LED灯带：槽位固定
  • 与电源线：连接端子

    • 材料选择： 白色PLA + 亚克力导光板

    2.11 水管快接头

    功能： 快速连接/断开水管，便于换水

    关键尺寸：

  • 内径：4mm（水管内径）
  • 外径：8mm（水管外径）
  • 接头长度：15mm
  • 连接端外径：10mm

    • 设计要点：

  • 快接头设计自锁结构，连接后不脱落
  • 设计O型圈密封（内径4mm）
  • 设计防脱卡扣，防止水管脱落
  • 接头设计流量控制阀（可选）
  • 接头需兼容标准4mm硅胶软管
  • 设计直角或直连两种规格

    • 配合关系：

  • 与水泵固定座：插接固定
  • 与过滤盒：插接固定
  • 与缸体：插接固定（通过底板开孔）

    • 材料选择： PLA或TPU（软性）

    五、3D打印工艺要求

    5.1 通用要求

    参数要求说明
    ------------------
    打印层高0.2mm平衡精度与速度
    填充率100%（关键件）/ 80%（普通件）结构强度要求
    壁厚最少3层保证密封性
    最小精度±0.2mm公差要求
    打印方向重要面朝下减少支撑痕迹

    5.2 各零件打印要求

    零件打印材料填充率支撑要求后处理
    ------------------------------------------
    底座外壳PLA100%需要（悬空>45°）打磨去毛刺
    底座上盖PETG100%需要打磨+抛光
    过滤盒PLA80%需要打磨去毛刺
    水泵固定座PLA100%需要打磨
    喂食器壳PLA80%需要打磨
    喂食转盘PLA100%不需要打磨轴孔
    LED固定座PLA80%需要打磨
    水管快接头TPU100%不需要去除支撑

    5.3 表面处理要求

  • 防水件（底座外壳、上盖）：打印后需涂防水胶或喷三防漆
  • 密封件：配合面需打磨光滑，确保密封效果
  • 外观件：外露面需打磨+抛光处理
  • 透明件（亚克力件）：激光切割后需去除毛刺，抛光处理

    • 六、装配工艺要求

    6.1 装配顺序

  • 电子件预装：PCB焊接完成后，固定到底座上盖
  • 底座组装：底座上盖+底座外壳密封装配
  • 缸体组装：亚克力板粘接（底板→侧板→顶盖）
  • 过滤系统：水泵固定→水管连接→过滤盒安装
  • 喂食系统：舵机安装→转盘安装→喂食器壳安装
  • 灯具系统：LED固定座安装→灯带嵌入→防水处理
  • 总装测试：密封测试→功能测试→外观检验

    • 6.2 关键装配要点

    工序要点检验标准
    ----------------------
    密封装配使用O型圈+硅胶密封打压测试不漏水
    粘接工艺亚克力粘接用UV胶或氯仿粘接牢固，无气泡
    螺钉固定M3螺钉扭矩0.3N·m不可过紧导致变形
    水管连接快接头卡扣锁紧拉扯不脱落

    七、公差与配合设计

    7.1 通用公差

  • 线性尺寸公差：±0.2mm
  • 孔径公差：+0.2mm（保证插入）
  • 轴径公差：-0.2mm（保证配合）
  • 角度公差：±1°
  • 形位公差：垂直度<0.5mm

    • 7.2 防水设计公差

  • O型圈沟槽：深度+0.05mm，宽度+0.1mm
  • 密封面平面度：<0.1mm
  • 螺钉孔位置度：<0.3mm
