# 智能鱼缸结构优化要求

## 优化核心

1. **背滤盒移到缸内后板内侧**（不在底座内）
2. **所有PCB和电子元件移到上盖上方**（不在底座内部）
3. **缸底空无一物**（只有亚克力底板）
4. **底座内只放水泵**
5. **喂食器+PCB在缸盖上方**

## 从上到下结构顺序

1. 喂食器壳体+喂食转盘（顶）
2. 缸盖 150x150x8mm（60mm喂食口+LED槽+通风孔+卡扣）
3. 缸体 150x150x150mm（背滤盒贴后板内侧，有水和小鱼）
4. 底板 150x150x2mm（光滑无元件，四周密封法兰）
5. 底座上盖 160x160x5mm（**上方承载PCB板+按键接口**，中央140x140mm开孔）
6. 底座外壳 160x160x48mm（仅结构+OLED屏+快插接头）
